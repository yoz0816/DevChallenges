## Overview

This project is my solution to the **Device Shop Checkout** challenge from devChallenges.

The goal was to recreate a responsive checkout page from the provided design and make it work across desktop, tablet, and mobile screen sizes.

### What I learned

While building this project, I practiced and improved my understanding of:

* Semantic HTML5 structure
* CSS Flexbox
* CSS Grid
* Responsive design
* Media queries
* Creating desktop, tablet, and mobile layouts
* Building responsive product cards
* Creating responsive forms
* Aligning Country and Postal Code fields in the same row
* Creating responsive coupon sections
* Working with images and SVG icons
* Using `min()`, `flex`, and `grid` for flexible layouts
* Matching a design more accurately with CSS spacing, sizing, and borders

## Features

* Responsive checkout page
* Product list with images, names, colors, prices, and quantities
* Remove-product icons
* Coupon code input
* Apply Coupon button
* Subtotal, tax, and total sections
* Contact information form
* Country selection
* Postal code input
* Responsive Country and Postal Code fields
* Responsive desktop, tablet, and mobile layouts
* Responsive background image
