## Overview

This project is a responsive pricing table created as part of a
[devChallenges](https://devchallenges.io/) challenge.

The goal was to reproduce the provided pricing table design while making
the layout responsive across desktop, tablet, and mobile screen sizes.

The pricing table includes four plans:

- Free
- Team
- Popular
- Enterprise

The Popular plan is visually highlighted to make it stand out from the
other pricing plans.

### What I learned

While working on this project, I practiced:

- Creating layouts with CSS Grid.
- Using Flexbox for smaller layout components.
- Creating responsive layouts with CSS media queries.
- Building a pricing table with multiple columns and rows.
- Hiding and displaying different pricing plans depending on screen size.
- Styling a highlighted pricing plan.
- Working with spacing, borders, colors, and typography.
- Using `min()`, `repeat()`, and `minmax()` with CSS Grid.
- Creating responsive mobile, tablet, and desktop layouts.
- Using semantic HTML elements such as `main`, `section`, and `article`.

One of the main things I practiced was using CSS Grid for the pricing
table because the design requires both rows and columns to line up.

### Useful resources

- [MDN CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout)
  - Helped me understand CSS Grid and its columns and rows.

- [MDN Flexbox](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Flexbox)
  - Helped me understand how to align elements inside the pricing cards.

- [MDN Media Queries](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_media_queries/Using_media_queries)
  - Helped me create responsive layouts for different screen sizes.
