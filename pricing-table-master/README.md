## Overview

This project is a responsive pricing table created as part of a
[devChallenges](https://devchallenges.io/) challenge.

The goal was to recreate the provided pricing table design using HTML and
CSS while making the layout responsive across different screen sizes.

The pricing table includes four plans:

- Free
- Team
- Popular
- Enterprise

The Popular plan is highlighted with a dark background and a different
call-to-action button to make it stand out from the other plans.

### What I learned

While working on this project, I practiced:

- Creating layouts with CSS Grid.
- Using Flexbox for component alignment.
- Creating responsive layouts with CSS media queries.
- Building a pricing table with multiple columns and rows.
- Creating different layouts for desktop, tablet, and mobile.
- Hiding and displaying pricing plans depending on screen size.
- Creating a highlighted pricing card.
- Working with CSS spacing, borders, colors, and typography.
- Using `repeat()` and `minmax()` with CSS Grid.
- Using semantic HTML elements such as `main`, `section`, and `article`.

The main challenge for me was aligning the pricing plans and feature rows
correctly using CSS Grid.

### Useful resources

- [MDN CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout)
  - Helped me understand how to create rows and columns with CSS Grid.

- [MDN Flexbox](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Flexbox)
  - Helped me understand alignment and positioning with Flexbox.

- [MDN Media Queries](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_media_queries/Using_media_queries)
  - Helped me create responsive layouts for different screen sizes.
