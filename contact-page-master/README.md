## Overview

This project is a responsive Contact Page built from a devChallenges design. It includes a responsive contact form with different layouts for desktop, tablet, and mobile screen sizes.

### What I learned

* Creating responsive layouts with CSS media queries.
* Using Flexbox and CSS Grid to structure the form.
* Building a two-column form layout for larger screens.
* Changing the form into a single-column layout on mobile devices.
* Working with responsive typography and spacing.
* Using SVG assets for the background, logo, and dropdown icons.
* Styling form inputs, textarea, labels, and buttons.

### Useful resources

* [MDN Web Docs](https://developer.mozilla.org/) - Useful reference for HTML and CSS.
* [W3Schools CSS](https://www.w3schools.com/css/) - Helped with responsive CSS and layout techniques.
* [devChallenges](https://devchallenges.io/) - Provided the original challenge design.

### Built with

* Semantic HTML5 markup
* CSS
* Flexbox
* CSS Grid
* CSS Media Queries
* Responsive Design
* SVG

## Features

* Responsive contact form
* Desktop, tablet, and mobile layouts
* Responsive typography
* Responsive two-column and single-column form layouts
* Custom background SVG
* Form input fields
* Company size dropdown-style field
* Subject dropdown-style field
* Message textarea
* Contact Sales button
