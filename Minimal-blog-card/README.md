## Overview

This project is a responsive minimal blog card built from a DevChallenges design. The goal was to recreate the provided design as closely as possible while practicing responsive layouts, typography, spacing, and CSS styling.

### What I learned

- How to create responsive layouts with CSS Flexbox.
- How to use `max-width` for responsive cards.
- How to match typography, spacing, colors, and shadows from a design.
- How to create a responsive card that works across desktop, tablet, and mobile screens.
- How to structure content using semantic HTML5 elements.

### Useful resources

- [W3Schools - CSS Flexbox](https://www.w3schools.com/css/css3_flexbox.asp) - Helped me understand and practice Flexbox.
- [MDN - CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) - Used as a reference for CSS properties and responsive styling.

## Built with

- Semantic HTML5 markup
- CSS3
- Flexbox
- Responsive Design
- Google Fonts

## Features

- Responsive blog card layout
- Desktop, tablet, and mobile support
- Minimal and clean UI
- Styled category badge
- Responsive image
- Custom typography
- Card shadow and rounded corners
