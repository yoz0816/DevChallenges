## Overview

This project is a responsive Simple FAQ page built from a DevChallenges design.

The page provides frequently asked questions about order tracking and the return policy. The layout is designed to work across desktop, tablet, and mobile screen sizes.

### What I learned

While working on this project, I practiced:

- Writing semantic HTML5 markup
- Creating responsive layouts with CSS
- Using CSS media queries
- Working with ordered and unordered lists
- Styling links and typography
- Creating responsive spacing and layouts for different screen sizes
- Improving mobile-first responsive design
- Matching a design across desktop, tablet, and mobile devices
